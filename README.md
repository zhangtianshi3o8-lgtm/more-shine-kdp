# More Shine Press — KDP Book Collection

**43 print-ready low-content and medium-content books** for Amazon KDP.  
Publisher: **More Shine Press** (墨香)

Each book directory contains:
- `generate.py` — interior page generator (Python, zero-dependency)
- `generate_cover.py` — full-wrap cover generator  
- `*_V1.0.html` — rendered interior HTML
- `*_V1.0.pdf` — print-ready interior PDF
- `*_cover_V1.0.html` — rendered cover HTML
- `*_cover_V1.0.pdf` — print-ready cover PDF
- `KDP_LISTING.txt` — Amazon listing metadata
