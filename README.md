## Structure
Each book directory contains:
- `generate.py` — interior page generator
- `generate_cover.py` — full-wrap cover generator
- `*_V1.0.html` — rendered HTML
- `*_V1.0.pdf` — print-ready PDF
- `KDP_LISTING.txt` — Amazon listing metadata
